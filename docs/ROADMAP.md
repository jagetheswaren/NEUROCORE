# Roadmap

## V0.1 — Stable Foundation

Completed: local Ollama integration, streaming, Markdown rendering, commands, Textual HUD, Rich fallback, sound controls, diagnostics, API surfaces, memory, knowledge components, and regression tests.

## V0.2 — Agent Core and Command Deck

Current milestone:

1. Command Deck workspace.
2. Shared `BaseAgent` contract and lifecycle states.
3. Agent Registry and truthful capability reporting.
4. Shared task model.
5. Event bus.
6. Planner, executor, and verifier boundaries.

Next increments:

1. Connect task/event data to Dashboard and Tasks screens.
2. Build the approval center.
3. Implement a bounded Coding Agent workflow.
4. Connect model tiers to actual request execution.
5. Add provider-neutral voice contracts.

## Later milestones

- V0.3: mission state, project memory, and agent-level RAG.
- V0.4: Voice Agent and Language Lab.
- V0.5: controlled filesystem, Git, terminal, and document actions.
- V0.6: verification, retries, cancellation, audit trail, and recovery.

Every milestone remains opt-in until its compatibility and safety gates pass.
